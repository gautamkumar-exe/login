# Responsive Login Page

A simple, clean, and responsive login page built using **HTML5 and CSS3** as part of my frontend development practice.

## Preview

The login page includes a centered login card with email and password fields, a Remember Me checkbox, a Forgot Password link, and a Login button.

## Features

- Clean and minimal user interface
- Email and password input fields
- Remember Me checkbox
- Forgot Password link
- Interactive button hover effect
- Input focus styling
- Responsive layout for mobile screens
- Flexbox-based alignment

## Technologies Used

- **HTML5** – Page structure and form elements
- **CSS3** – Styling, layout, transitions, and responsiveness

## Concepts Practiced

Through this project, I practiced:

- HTML boilerplate and semantic form elements
- CSS selectors and properties
- CSS Box Model
- Flexbox (`display: flex`, `justify-content`, `align-items`)
- Pseudo-classes (`:hover`, `:focus`)
- CSS transitions
- Media queries
- Responsive web design
